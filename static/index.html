PROJECT INFORMATION

About SENTINEL

A machine-learning application for network traffic classification.

Purpose-built detection

SENTINEL classifies uploaded network connection records into normal or attack categories using an existing trained Random Forest model.

Machine learning pipeline

CSV input → Feature validation → Categorical encoding → Feature alignment → Random Forest prediction → Report generation.

Technology stack

Python, Flask, HTML, CSS, JavaScript, Pandas, Scikit-learn and Joblib.

Scope and limitations

This version analyzes uploaded CSV datasets. It does not capture live packets, block traffic, or provide real-time network protection.
